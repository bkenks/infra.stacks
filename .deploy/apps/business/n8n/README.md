# n8n

[n8n](https://n8n.io/) — workflow automation. Reached at `n8n.ktbinternal.com` via Traefik → port 5678.

Source of truth: `compose.jsonnet` — don't edit the generated YAML (renders both `compose.yaml` and `compose.stack.yaml`).

## Deploy

Deployed via Komodo. Needs `/dev/shm/postgres.env` (shared Postgres, `postgres-db:5432`, db `n8n`) — no secrets of its own. `N8N_ENCRYPTION_KEY` is auto-generated by n8n on first boot and persisted in the bind-mounted `.n8n` dir; don't add it to Infisical.

Gotchas:
- `app` sets `dns: [192.168.1.6, 1.1.1.1]` so `*.ktbinternal.com` resolves inside the container for LAN-only integrations (e.g. Carbone) — don't remove without confirming those still resolve.
- Must run as the default `node` user (UID 1000). Setting `user: "0:0"` silently wipes data on every redeploy (writes to the container's ephemeral layer instead of the bind mount).
